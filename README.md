# IMS Frontend

Giao diện quản lý hệ thống kho (Inventory Management System).

## Công nghệ sử dụng
- React 18 + TypeScript + Vite
- Tailwind CSS
- Axios & TanStack Query
- Zustand

## Cài đặt & Khởi chạy

```bash
# Cài đặt thư viện
npm install
# hoặc
pnpm install

# Khởi chạy môi trường phát triển
npm run dev
```
